# SOC Rule-Reasoning Investigation for Incident #16100: "Heavy TCP Host Scan On Fixed Port"

---

## **Section A: Incident Overview & Rule Definition**

**Rule Name:** `PH_RULE_HEAVY_TCP_HOST_SCAN_FIXED_PORT`  
**Rule Description:** This rule is triggered when a large number of TCP packets are sent to the same destination port across multiple unique destination IPs within a short time window, indicating a potential host scan or reconnaissance activity.

**Rule Threshold:**  
- `COUNT(DISTINCT destIpAddr) >= 100`  
- **Time Window:** 180 seconds (3 minutes)  
- **Group-by Fields:**  
  - `source_ip`  
  - `dest_port`  
  - `timestamp` (within the 180s window)

**Purpose:** Detect potential scanning behavior where a single source IP sends TCP packets to multiple unique destination IPs on the same fixed port, which is a common pattern in network reconnaissance.
