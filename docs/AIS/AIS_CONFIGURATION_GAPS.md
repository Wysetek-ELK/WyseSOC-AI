## 2. Immediate Configuration Hygiene Observations

1. **Root Empty SQLite Trap:** Repo root contains a 0-byte `ai_verdict.db`, while the actual dev DB is `backend/ai_verdict.db` (`4.7 MB`, resolved via `BASE_DIR` in `config.py:5-6`).
2. **Permissive Local Fallbacks (`backend/.env`):** `FORTISIEM_MOCK_FALLBACK=true` and `LOCAL_LLM_ALLOW_MOCK_FALLBACK=true` are active locally. Ensure production `.env` strictly follows `deployment/env.production.example` (`false` for both, strong `SECRET_KEY` and `AUDIT_SIGNING_KEY`, `FORTISIEM_VERIFY_SSL=true`).
3. **Sync Simulation Timeout Risk:** Because AIS `evaluate-simulation` executes synchronously inside the HTTP request (`prompts.py:553`) rather than on Celery queue `simulation_replay`, enabling real `OPENAI_COMPATIBLE` inference across 50+ incidents over HTTP risks gateway timeouts unless dispatched asynchronously.
