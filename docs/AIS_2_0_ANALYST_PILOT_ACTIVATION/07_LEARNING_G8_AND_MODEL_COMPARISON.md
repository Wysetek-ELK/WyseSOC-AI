## 3. Post-Submission Model Comparison & Fallback Verification

Upon successful submission of an analyst review, the backend returns the enriched comparison payload:
- **Analyst Determination:** `TRUE_POSITIVE`, `FALSE_POSITIVE`, or `INSUFFICIENT_EVIDENCE`.
- **Raw Local LLM Verdict:** Stored model output from Server 2.
- **Governed Effective Verdict:** Verdict following application of system safety guardrails.
- **Policy Version:** Exact version number (e.g. `v2`).
- **Model Reasoning:** Summarized explanation from the model capture.
- **Agreement Outcome:** Computed comparison classification (`AGREEMENT_TP`, `AGREEMENT_FP`, `AI_FALSE_ALARM`, `CRITICAL_MISSED_TP`, `ANALYST_INSUFFICIENT_EVIDENCE`, `ANALYST_RESOLVED_ABSTENTION`).
- **Missing AI Evaluation Fallback:** If an incident has not yet undergone model inference, the UI displays **`AI Evaluation Not Available`** instead of fabricating a default verdict or inferring false agreement.

## 4. Empirical Accuracy & Confusion Matrix Formulas

The empirical metrics computed by `RuleLearningService` are mathematically defined as:

1. **Overall Accuracy:**
   $$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN} = \frac{\text{Agreed TP} + \text{Agreed FP}}{\text{Total Decisive Reviews}}$$

2. **FP-Class Precision (Precision of Benign Classifications):**
   $$\text{FP Precision} = \frac{TN}{TN + FN} = \frac{\text{Agreed FP}}{\text{Agreed FP} + \text{Critical Missed TP}}$$
   *Measures the reliability of benign/false-positive classifications.*

3. **Specificity (True Negative Rate):**
   $$\text{Specificity} = \frac{TN}{TN + FP} = \frac{\text{Agreed FP}}{\text{Agreed FP} + \text{AI False Alarm}}$$
   *Measures the proportion of actual benign traffic correctly identified by the AI.*

4. **TP-Class Precision:**
   $$\text{TP Precision} = \frac{TP}{TP + FP} = \frac{\text{Agreed TP}}{\text{Agreed TP} + \text{AI False Alarm}}$$

5. **TP Recall:**
   $$\text{TP Recall} = \frac{TP}{TP + FN} = \frac{\text{Agreed TP}}{\text{Agreed TP} + \text{Critical Missed TP}}$$

6. **Wilson Score 95% Binomial Confidence Lower Bound ($W_{LB}$):**
   $$W_{LB} = \frac{\hat{p} + \frac{z^2}{2n} - z \sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}} \quad (\text{with } z = 1.96)$$
