# 08. HONEST CONFIDENCE CALIBRATION

**Document Identifier:** `AV-P3-DOC-08`  
**Requirement Mapping:** `P3-REQ-07` (Honest Confidence Calibration Reporting)  
**Implementation Modules:** `app/services/calibration_evaluation_service.py`, `app/schemas/calibration.py`  

---

## 1. Safety Correction: Confidence vs. Validation

In the Phase 2 baseline audit, a critical nuance was identified:
> "A passed evidence validator does not make an LLM confidence score statistically calibrated."

When the independent validator accepts a decisive verdict (e.g. TRUE_POSITIVE), it confirms that mandatory telemetry exists, claims cite real evidence IDs, and indicators meet the policy contract. However, that deterministic verification does not magically transform the LLM's raw self-reported confidence (e.g., 94%) into a calibrated posterior probability.

---

## 2. Thirty-Sample Minimum Calibration Policy

Phase 3 introduces a mandatory governance rule:
- **Sample Threshold:** Minimum 30 independently adjudicated ground-truth cases per detection rule.
- **Below Threshold ($N < 30$):**
  - Calibration status is marked as `NOT_CALIBRATED`.
  - The API and UI explicitly report:
    `"INSUFFICIENT_SAMPLE_SIZE: Only N verified ground-truth cases available (minimum required: 30). In accordance with Phase 3 safety standards, confidence calibration is WITHHELD. Model confidence must be interpreted as raw, uncalibrated heuristic scores."`
  - `is_calibrated` is explicitly set to `False`.
- **At or Above Threshold ($N \ge 30$):**
  - Platt scaling or isotonic calibration may be computed.
  - Brier score and Expected Calibration Error (ECE) are published in `RuleCalibrationReport`.
  - Status transitions to `CALIBRATED`.

---

## 3. UI and API Presentation

In the workbench UI and API responses, numbers are cleanly separated:
1. `raw_model_confidence`: The raw score generated by the model (e.g., 94.0%).
2. `confidence`: The validated confidence display value.
3. `calibration_status`: Explicitly `NOT_CALIBRATED` (with yellow badge).
4. `evidence_completeness`: The deterministic fraction of required contract fields present in telemetry (e.g., 100%).
5. `grounding_ratio`: The deterministic fraction of model claims grounded in canonical evidence (e.g., 100%).

Analysts can clearly distinguish between factual evidence verification and statistical calibration.
